# 无限副本资源目录

本目录独立存放无限副本。页面根据 `src/content/infiniteStories.ts` 中的主题 ID 与子文件夹 ID 呈现层级；每个主题目录下的 `theme.png` 用作该主题背景，位于子文件夹旁。

无限副本首页从每个子文件夹的 `story.md` 元数据读取入口标题；点击入口后，剧情回顾页面读取同一文件的正文和图片。正文的段落、对白格式与世界任务相同。

## 剧情分支格式

在正文中使用四级标题 `#### 分支选择` 开始一个选择区。标题下每个不缩进的一级列表项是一条可选对白；选项对应的差分剧情缩进两个或更多普通空格。列表结束后，不缩进的正文会作为共通剧情继续显示。差分中的对白与动作、不同段落之间仍空一行。

分支选项可以直接写提示词，例如“崩掉他”，不需要说话人前缀，也不会显示说话人框；后续差分剧情可以重复提示词。只有选项本身是实际对白时，才在列表项中写说话人前缀；所有选项的说话人相同时，页面会将前缀提取到选项组上方的说话人框中。

分支结局写在对应选项的差分剧情末尾，并缩进两个普通空格，格式为 `#### 【结局一 浮沉】`。结局标题会显示在正文中，也会作为当前三级标题下的目录子项显示；点击目录项后切换到对应选项并跳转至结局位置。选中结局后，该选项后续内容以及之后的小节不会继续显示，因此结局标题应放在该分支剧情的最后。

```md
#### 分支选择

- 分支提示词1

  说话人：说话内容

  旁白1。

  #### 【结局一 示例】

- 分支提示词2

  旁白2。

正文继续。
```

回顾页面会把选项显示在带边框的选择区内，当前选项高亮；选择后，对应差分显示在框内。选项状态会在当前浏览器会话中保留。

目标层级：

```text
public/infinite_stories/
├── ShiDaiJiuYing/
│   ├── theme.png
│   ├── CanKuJieMu/story.md
│   └── TaDeYouXi/story.md
└── XianTuPiaoMiao/
    ├── theme.png
    └── TianDiWuShu/story.md
```

把原先 `public/world-quests/` 下对应主题中的副本文件夹移动到这里的同名主题目录下。保留 `story.md` 与 `images/` 的相对结构；正文标题、简介和内容仍从 `story.md` 读取。
