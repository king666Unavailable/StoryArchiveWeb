# 世界任务素材目录

按“主题 ID / 子任务 ID”放置每项任务的正文和素材。

- 在对应子任务目录粘贴或创建 `story.md`。文件开头的 YAML frontmatter 提供页面资料，下面编写故事正文。
- 将该子任务用到的图片放进同目录的 `images/`。
- 在 frontmatter 中填写 `image: images/文件名.png`，页面会将它显示在右侧场景区域；省略 `image` 时图片区域保持空白。
- 人物头像可填写 `avatar: images/头像文件.png`；有 `character` 但没有 `avatar` 时显示空框占位，`character` 留空时不显示人物区域。
- 主题名称和子任务 ID 在 `src/content/worldQuests.ts` 中维护；`story.md` 提供标题、简介、时期、人物和类型。
- 类型填写 `world_quests` 或 `infinite_stories`；人物留空时页面不显示人物区域。

## 剧情分支格式

在正文中使用四级标题 `#### 分支选择` 开始一个选择区。标题下每个不缩进的一级列表项是一条可选对白；选项对应的差分剧情缩进两个或更多普通空格。列表结束后，不缩进的正文会作为共通剧情继续显示。差分中的对白与动作、不同段落之间仍空一行。

分支选项可以直接写提示词，例如“崩掉他”，不需要说话人前缀，也不会显示说话人框；后续差分剧情可以重复提示词。只有选项本身是实际对白时，才在列表项中写说话人前缀；所有选项的说话人相同时，页面会将前缀提取到选项组上方的说话人框中。

分支结局写在对应选项的差分剧情末尾，并缩进两个普通空格，格式为 `#### 【结局一 浮沉】`。结局标题会显示在正文中，也会作为当前三级标题下的目录子项显示；点击目录项后切换到对应选项并跳转至结局位置。选中结局后，该选项后续内容以及之后的小节不会继续显示，因此结局标题应放在该分支剧情的最后。

```md
#### 分支选择

- 分支提示词1

  说话人：说话内容

  旁白1。

  #### 【结局一 示例】

- 分支提示词2

  旁白2。

正文继续。
```

回顾页面会把选项显示在带边框的选择区内，当前选项高亮；选择后，对应差分显示在框内。选项状态会在当前浏览器会话中保留。

例如：

```text
ShiDaiJiuYing/
  AiShaYiYuan/
    story.md
    images/
      preview.webp
```
